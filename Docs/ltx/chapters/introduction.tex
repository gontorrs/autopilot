\chapter{Introduction}
\setcounter{section}{0}

Autopilot is a fully autonomous desktop automation system for Windows that accepts a single spoken natural language command and executes the described task without any further human interaction. The system is designed for users with limited motor function who cannot rely on a keyboard or mouse, and operates entirely on the local device without transmitting any data off the device. Its architecture combines a deterministic symbolic planner with a local VLMs and LLMs, forming a neuro-symbolic pipeline that is evaluated against four alternative systems across eleven performance, reliability, and privacy metrics.

\section{Problem description}

People with reduced motor function face a fundamental barrier when using a personal computer, every standard input method assumes physical ability. Voice-based accessibility tools available today address this with some drawbacks.

There are systems, such as Windows Voice Access, that map a fixed vocabulary of phrases to individual actions. The user must memorise the exact phrasing for each operation and input one command per step, which effectively shifts the planning effort from the machine to the user. 

Autonomous cloud-based agents can interpret free-form natural language and execute multi-step tasks without step-by-step guidance. However, they transmit screenshots, file names, and task descriptions to remote inference servers on every action, this is a huge drawback for users who handle sensitive documents or who operate without a reliable internet connection. Furthermore, these systems are reactive rather than planned, they capture a screenshot, decide an action, execute it, and repeat, which leads to non-optimal and inconsistent execution paths in complex tasks.

Autopilot addresses both limitations. It accepts a single free-form voice prompt and executes the described task autonomously from start to finish, with no further interaction required. All inference runs locally on consumer-grade hardware, no data leaves the device at any point, and the action sequence is generated by a deterministic symbolic planner that guarantees a minimal and reproducible execution path.
